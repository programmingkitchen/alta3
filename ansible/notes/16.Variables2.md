# Advanced Variable Methods in Ansible (vars_prompt, register, set_fact)

## General ideas 

### Use Cases for register
- Capturing command output for use in later tasks.
- Checking whether a task made changes and acting conditionally.
- Debugging or logging detailed task results.

### Use Cases for set_fact

- The set_fact module lets you create or update variables during playbook execution, for example get the current date and create a directory with that name.

**Use Cases**
- Defining variables dynamically based on task outputs.
- Simplifying complex playbooks by creating reusable variables.
- Adjusting variables dynamically during execution, such as creating temporary paths or conditional settings.

## Prompting for a variable
- This prints out an encrypted password in sha512
- Comment out
- default
- encrypt
- confirm

```yaml
---
- name: How to prompt for variables
  hosts: localhost
  gather_facts: no

  vars_prompt:
    - name: "yourpassword"
      prompt: "What is your password?"
      private: yes
      encrypt: "sha512_crypt"
      confirm: yes
      salt_size: 7
      default: "qwerty"

  tasks:
    - name: Print out the password
      debug:
        msg: "{{ yourpassword }}"
```
