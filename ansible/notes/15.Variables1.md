- Playbook passing in variables from the inventory. 
- It will find the variables in the inventory 
- This is also an example of how to use the shell 

```bash
- name: Jurassic Park Tour
  hosts: bender
  tasks:
    - name: Announce the dinosaur
      shell: |
        echo "Our next stop will take us past the {{ dino_name }}. It loves eating {{ dino_food }}.
        You should be able to see it if you look {{ dino_direction }}" >> /tmp/jurassicpark.txt
```

- Now we are going to reference a vars file and make that override everything else, including the inventory. 

- vars file

```bash
student@bchd:~/mycode/vars$ cat dino_vars.yml 
dino_name: Stegosaurus
dino_food: "ferns and mosses"
dino_direction: "to your left"
```

- The reference to the vars file including all of the other references. 

```bash
───────┬─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────
       │ File: jurrassic_tour03.yaml
───────┼─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────
   1   │ - name: Jurassic Park Tour 03
   2   │   hosts: bender
   3   │   vars_files:
   4   │     - ~/mycode/vars/dino_vars.yml
   5   │   vars:
   6   │     dino_name: Velociraptor  # Overrides host variable
   7   │     dino_food: "small mammals and lizards"
   8   │     dino_direction: "to your right"
   9   │   tasks:
  10   │     - name: Announce the dinosaur
  11   │       shell: |
  12   │         echo "Our next stop will take us past the {{ dino_name }}. It loves eating {{ dino_food }}.
  13   │         You should be able to see it if you look {{ dino_direction }}" >> /tmp/jurassicpark.txt
───────┴─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────
```

```bash

   8   │     - name: Announce the dinosaur
```
