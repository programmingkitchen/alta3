- Playbook passing in variables from the inventory. 
- It will find the variables in the inventory 
- This is also an example of how to use the shell 

```bash
- name: Jurassic Park Tour
  hosts: bender
  tasks:
    - name: Announce the dinosaur
      shell: |
        echo "Our next stop will take us past the {{ dino_name }}. It loves eating {{ dino_food }}.
        You should be able to see it if you look {{ dino_direction }}" >> /tmp/jurassicpark.txt
```

- Output on bender

```bash
bender@bender:~$ cd /tmp
bender@bender:/tmp$ ls

bender@bender:/tmp$ cat jurassicpark.txt
```

- Now we override those by defining the varialbes in the file 

```bash
student@bchd:~/mycode$ batcat jurrassic_tour02.yaml 
───────┬─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────
       │ File: jurrassic_tour02.yaml
───────┼─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────
   1   │ - name: Jurassic Park Tour 02
   2   │   hosts: bender
   3   │   vars:
   4   │     dino_name: Velociraptor  # Overrides host variable
   5   │     dino_food: "small mammals and lizards"
   6   │     dino_direction: "to your right"
   7   │   tasks:
   8   │     - name: Announce the dinosaur
   9   │       shell: |
  10   │         echo "Our next stop will take us past the {{ dino_name }}. It loves eating {{ dino_food }}.
  11   │         You should be able to see it if you look {{ dino_direction }}" >> /tmp/jurassicpark.txt
───────┴─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────
student@bchd:~/mycode$ 
```
