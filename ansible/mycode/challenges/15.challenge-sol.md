# Variables Challenge Solution
- Here’s how to define fav_movie using different Jurassic Park movies for each location, demonstrating variable precedence. You didn't have to do all of these, this is just for reference.

## 1. Inventory File

- Add the lowest-precedence version of fav_movie to the inventory file:

```bash
fry ansible_host=10.10.2.4 ansible_user=fry fav_movie="Jurassic Park"
```


## 2. Variables File

- Create a vars_files file with the next version of fav_movie:

```bash
# ~/mycode/vars/movies.yml
fav_movie: "Jurassic Park: The Lost World"
```

## 3. Play Variables

- Define another version of fav_movie in the playbook itself:

```bash
vars:
  fav_movie: "Jurassic Park III"
```

## 4. Task Variables

- Add the highest-precedence version of fav_movie to the specific task:

```bash
- name: Create directory for favorite movie
  file:
    path: "/tmp/{{ fav_movie }}"
    state: directory
  vars:
    fav_movie: "Jurassic World"
```

## 5. Extra Variables

- And yes, you can use -e as well!
