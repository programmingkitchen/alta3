# 14. Understanding and Using the Loop Keyword in Ansible

## Code

```bash
- hosts: bender
  become: true

  vars:
    delorean:
      - { name: 'marty', shell: '/bin/bash' }
      - { name: 'doc', shell: '/bin/zsh' }

  tasks:
    - name: Create users
      user:
        name: "{{ item.name }}"   # look at the value of "name" above
        shell: "{{ item.shell }}" # look at the value of "shell" above
        state: present
      loop: "{{ delorean }}"

    - name: Debug user details
      debug:
        msg: "Created user {{ item.name }} with shell {{ item.shell }}"
      loop: "{{ delorean }}"
```

## Parsing questions 

- Looping over a data structure called "delorean" ?
- This is a list of dictionary items 
- This appears to be a completly separate loop that does not actually reveal REAL success or failure.  It's just another loop
- We are going to try it again without the actual creation of the users

```bash
TASK [Debug user details] ***********************************************************************************************************

}
```

## Two fun programs for Ubuntu

- apt takes a list 
- This is in contrast to modules like "user" (see above) that will not create a list. 


```bash
- hosts: fry
  tasks:
    - name: Install packages
      apt:
        name:
          - sl
          - cmatrix
        state: present
      become: true

```
